Host Free on GitHub Pages & Fix 404

If you saw a 404 Not Found error after publishing, it's usually because GitHub Pages takes 1–2 minutes to build, or the file was named incorrectly or placed in the wrong spot. Here is how to create or update your file correctly:

Critical Rule: File Name

The file in your GitHub repository must be named exactly index.html (all lowercase, no spaces or parentheses like `index (1).html`).

Step 1: Download the Correct File

Click below to download the fresh, fully packaged index.html file.

Step 2: How to Update in GitHub
  1. Go to your repository on github.com.
  2. If there is already an incorrectly named file (like index (1).html), click on it, click the Trash can icon to delete it, and click Commit changes.
  3. Click Add file → Upload files at the top right of your repository file list.
  4. Drag and drop your newly downloaded index.html file into the upload box.
  5. Ensure the filename shown is strictly index.html.
  6. Click Commit changes at the bottom.
Step 3: Verify GitHub Pages Settings
  1. Go to your repository's Settings tab at the top.
  2. Click Pages in the left sidebar.
  3. Under Build and deployment > Branch, verify it is set to main (or master) and / (root) folder, then click Save if changed.
  4. Wait 1–2 minutes for GitHub to deploy, then click your live link!
