Host Free on GitHub Pages

Because this web app is self-contained in a single HTML file, you can host it online completely free on GitHub Pages!

Step 1: Save the code file

Download or copy the index.html code from this editor window onto your computer.

Step 2: Create a GitHub Repository
  1. Go to github.com/new and sign in.
  2. Name your repository (e.g., meal-planner).
  3. Set visibility to Public and click Create repository.
Step 3: Upload index.html
  1. In your new repo, click uploading an existing file.
  2. Drag & drop your index.html file.
  3. Click Commit changes.
Step 4: Enable GitHub Pages
  1. Go to Settings → Pages in your repo menu.
  2. Under Build and deployment > Branch, select main (or master) and click Save.
  3. In 1–2 minutes, your website link (e.g. https://username.github.io/meal-planner) will be live!
